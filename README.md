# Tetris v2
---
### Controls
```txt
[C] hold           [↑]    Rotate
[SPACE] place   [←][↓][→] Move
```

---
### Installation
```bash
git clone https://github.com/miguelandin/tetris-py.git
cd tetris-py
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
